# Calculator Project

A modern and responsive calculator built using HTML, CSS, and JavaScript.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Clear button (C)
- Real-time calculations
- Responsive design
- User-friendly interface
- Keyboard support (optional)

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```
calculator-project/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` in any web browser.
